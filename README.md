# Kamran Ali Portfolio Website

A modern, professional, and responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Files

- `index.html` – Main structure and portfolio sections
- `style.css` – Visual design and responsive layout
- `script.js` – Mobile menu and small UI behavior

## Run Locally

1. Clone/download the project.
2. Open `/home/runner/work/Project/Project/index.html` in any modern browser.

No build step or dependency installation is required.

## Customize

- Update text in `index.html` for personal details, projects, and contact info.
- Adjust colors, spacing, and typography in `style.css`.
- Extend interactive features in `script.js`.
